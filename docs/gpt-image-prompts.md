Пропорции:
- шаги процесса — **горизонтальные 3:2** (1536×1024), на сайте обрезаются до 16:10;
  важное держите в центре кадра;
- разрез — **квадрат 1:1** (1024×1024).

Настоящие работы (галерея, «до/после») берём **только** с Авито. Сгенерированные
кадры нельзя выдавать за реальные объекты.

## Общий стиль (отправить в чат первым)
Стиль подобран под уже готовый главный кадр.

```
Делаем серию фотореалистичных кадров для сайта компании, которая остекляет, утепляет
и отделывает балконы и лоджии в обычных российских многоэтажках. Стиль во всех кадрах
должен совпадать с первым кадром серии (светлая лоджия, бежевые стены, белые ПВХ-окна,
пол под дуб, оливковые текстили, тёплый закатный свет):
- фотореализм, интерьерная съёмка, объектив 24–35 мм, без «рыбьего глаза»;
- мягкий тёплый свет «золотого часа» или ровный дневной; тёплые бежевые и древесные тона;
- реалистичные российские детали: панельные дома за окном, белые ПВХ-окна;
- без роскоши, всё аккуратно и правдоподобно;
- НИКАКОГО текста, надписей, логотипов, брендов на материалах и одежде;
- у людей нет узнаваемых лиц: съёмка со спины, руки, лицо вне фокуса;
- без искажённых рук, лишних пальцев и «плавающих» предметов.
Формат каждого кадра укажу отдельно. Подтверди и жди задания.
```

## step-1-call — Звонок · 3:2 горизонтальный
```
Формат 3:2, горизонтальный. Крупный план: рука держит смартфон на фоне старого
неутеплённого балкона — облупленная краска, старые деревянные рамы, пустой бетонный пол,
за окном двор с панельными домами. Экран телефона показывает входящий/исходящий вызов,
но без читаемого текста (размыт). Малая глубина резкости: в фокусе рука и телефон,
балкон размыт. Холодноватый дневной свет снаружи, лёгкий тёплый свет из комнаты сбоку.
```

## step-2-measure — Замер · 3:2 горизонтальный
```
Формат 3:2, горизонтальный. Пустая бетонная лоджия до ремонта, уже с новыми белыми
ПВХ-окнами или со старыми рамами. Мастер в аккуратной тёмно-синей рабочей одежде без
логотипов, снят со спины или вполоборота, лицо вне фокуса, измеряет стену лазерной
рулеткой (видна красная точка на стене). На подоконнике лежат планшет и веер образцов:
кусочек сосновой вагонки, планка ламината под дуб, белая ПВХ-панель, оранжевый
пеноплекс. Дневной мягкий свет. Главное — мастер и образцы в центре кадра.
```

## step-3-contract — Договор · 3:2 горизонтальный
```
Формат 3:2, горизонтальный. Вид сверху под углом 45° на светлый кухонный стол:
распечатанная смета и договор (текст неразборчив, размыт), ручка, лазерная рулетка,
образцы отделки — сосновая вагонка, планка ламината под дуб, кусок оранжевого
пеноплекса, фольгированный пенофол. Две руки: одна передаёт ручку другой. Чашка чая,
оливковая салфетка. Тёплый домашний свет, спокойная деловая атмосфера.
```

## step-4-works — Работы · 3:2 горизонтальный
```
Формат 3:2, горизонтальный. Процесс утепления той же лоджии: новые белые ПВХ-окна уже
стоят. На стенах смонтированы оранжевые плиты пеноплекса, часть стены уже закрыта
серебристым фольгированным пенофолом со швами, проклеенными алюминиевым скотчем, поверх
идут деревянные бруски обрешётки. На полу деревянные лаги и пеноплекс между ними.
Аккуратная стройка: инструмент сложен, мусора нет, людей нет или видны только руки
с шуруповёртом. Тёплый дневной свет.
```

## layers-cutaway — Разрез утепления · 1:1 квадрат
```
Формат 1:1, квадрат. Архитектурная 3D-визуализация: угол лоджии в аксонометрии, как
макет на светлом холодно-сером фоне (#E7ECEB). Стена и пол разрезаны, слои немного
раздвинуты (exploded view), с ровными зазорами.
Стена от улицы внутрь: светлый силикатный кирпич → белая гидроветрозащитная мембрана →
оранжевый пеноплекс 50 мм → серебристый пенофол → сосновые бруски обрешётки →
светлая вертикальная вагонка.
Пол снизу вверх: серая бетонная плита → тёмная гидроизоляция → деревянные лаги
с оранжевым пеноплексом между ними → светлый лист ГВЛ → тонкая тёмная плёнка тёплого
пола с медными полосами → ламинат под тёплый дуб.
Мягкий студийный свет, мягкие тени, чистый минимализм. Без текста, подписей и стрелок.
```
